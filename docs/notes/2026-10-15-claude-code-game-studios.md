# Claude Code 游戏工作室

最近在 X 上刷到有人用 Opus5.5，花了 16 天时间，将《小王子的故事》做成了 3D 游戏，[游戏地址](https://littleprince.dev/)。试玩了一下，做得是真好看啊，这以后如果有版权，都可以自己开发游戏出来了。

我想到了前段时间 github 上有一个热门的项目 [Claude-Code-Game-Studios](https://github.com/Donchitos/Claude-Code-Game-Studios)，打造一个基于 Claude Code 的游戏工作室。完整的游戏工作室所需要的角色，它都有，只不过以 Agent 形式存在。它通过 49 个 AI 智能体、74 个工作流技能和一套完整的协调系统，模拟真实游戏工作室的层级结构，为 AI 辅助游戏开发引入流程与纪律。

## 解决的痛点

单独使用 AI 进行游戏开发时，对话缺乏结构——没有 QA 环节、没有设计评审，AI 可能硬编码魔法数字、跳过设计文档或写出难以维护的代码。该项目为 AI 会话赋予了真实工作室的架构：导演把控愿景、部门主管负责各自领域、专家执行具体工作，每个智能体都有明确的职责、升级路径和质量关卡。你仍然是所有决策的最终拍板人，但团队会主动提出正确的问题、及早发现错误，让项目从头脑风暴到发布都保持有序。
