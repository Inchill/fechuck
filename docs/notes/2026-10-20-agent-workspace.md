# 编码不再是瓶颈之后

coding agent 写代码已经很快了，但整体交付并没有快多少。

因为写代码只是其中一环。真正耗时的是**搬运上下文**：需求在 PRD 文档里，设计取舍在某次讨论里，接口约定在另一个仓库，怎么发版只有我知道。每次开工，都得先把这些喂给它。

![编码变快了，交付却没快多少](/2026/agent-workspace/delivery.png){data-zoomable}

所以下一步提效的关键，是给它一个完整的 **workspace**：多个仓库、写给它看的文档、沉淀成 skill 的流程、能直接调用的工具，以及跑得起来的环境。

其中最重要的是**反馈闭环**。测试、CI、日志是它的感官，有了这些，它能自己“改、跑、看、再改”，我只在关键节点拍板。

![给 AI 一个完整的 workspace](/2026/agent-workspace/workspace.png){data-zoomable}

另外，workspace 要能持续沉淀，agent 踩过的坑要写回去，否则每个任务都是第一天上班。

我的角色也在变：写代码少了，更多是在经营这个 workspace。接下来打算拿自己的项目实际搭一遍，再写篇复盘。
